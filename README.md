# Proyecto Kevin · versión 6 integrada

Cada HTML incorpora su diseño, fondo, funciones y bibliotecas. Evolución incorpora también la malla humana. Las tres páginas se alojan juntas en el mismo repositorio, compartiendo tus registros en el navegador.

## Corregir la publicación

1. Extraé este ZIP en tu computadora.
2. En `ProyectoKevin`, usá **Add file → Upload files**.
3. Subí los tres archivos: `index.html`, `rutas.html` y `evolucion.html`, con esos nombres exactos, reemplazando las versiones anteriores. Confirmá **Commit changes**.
4. Esperá a que termine de publicar GitHub Pages. En el repositorio, podés revisar la sección **Actions** y esperar que la publicación termine correctamente.
5. Abrí tu web y presioná **Ctrl + F5**. En Windows, el archivo inicial se puede abrir también haciendo doble clic sobre `index.html` para comprobar el diseño antes de subirlo.

No hace falta subir archivos adicionales de diseño o funciones para esta versión. Las páginas existentes se pueden reemplazar juntas en un solo commit. El README y `.nojekyll` son auxiliares.

Los archivos HTML mantienen la clave de registros anterior `mi-evolucion-v1`. Al entrar por el mismo navegador y la misma dirección, siguen disponibles tus controles y hábitos. Los respaldos anteriores se pueden restaurar desde Datos y ajustes.

## Qué funciona sin conexión

Diseño, fondo, checklist, controles, gráficos y bienestar. La malla de Evolución está incorporada; en un dispositivo sin WebGL se muestra una proyección alternativa de la misma figura.

El clima, las rutas calculadas y los mapas requieren conexión. Si esos servicios fallan, la interfaz muestra el estado correspondiente y sigue funcionando el seguimiento local.

GitHub publica la web y su código. Los registros personales se guardan en este navegador, con exportación e importación por JSON.

La figura es orientativa y cambia con las medidas registradas. Un nuevo peso sin medidas no inventa otro contorno. Las explicaciones de beneficios potenciales y las percepciones que vos anotás se muestran por separado.

## Créditos

Three.js 0.160.1 (MIT), Leaflet 1.9.4 (BSD 2-Clause), malla humana adaptada de recursos CC0 de MakeHuman. Los textos de licencias están incorporados en los scripts correspondientes de cada HTML. El fondo fue generado para este proyecto. Mapas: OpenStreetMap; recorridos: FOSSGIS / OSRM; clima: Open-Meteo.
